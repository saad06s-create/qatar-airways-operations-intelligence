# ✈️ Qatar Airways Operations Intelligence Platform

**End-to-end aviation data analytics project using Python, SQL, Plotly & Power BI**

This project analyses airline operational performance using real-world flight data to investigate delays, aircraft utilisation, airport efficiency and route reliability.

---

## Project Status

🚧 In Development

---

## Objectives

* Analyse flight punctuality across an airline network
* Identify the causes of departure delays
* Measure airport and aircraft operational efficiency
* Build an executive dashboard for airline decision-makers

---

## Tech Stack

* Python
* Pandas
* SQL (SQLite)
* Plotly
* Power BI
* Git & GitHub
